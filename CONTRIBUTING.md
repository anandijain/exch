# Contributing

## Public Repository Rule

This repository is public. Treat every committed file as publishable.

Before committing or pushing, check that the change does not include:

- API keys, tokens, passwords, cookies, or private certificates;
- private hostnames, IP addresses, account IDs, or cloud resource names;
- local network details that should not be public;
- real customer, personal, trading, or financial data;
- paid/proprietary exchange data that cannot be redistributed;
- generated logs or captures that may contain any of the above.

Use sample fixtures, fake credentials, and redacted examples instead. If a private file is useful
locally, keep it untracked and add an ignore rule for its path or file pattern.
